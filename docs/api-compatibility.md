# API Compatibility

See `docs/api/api-compatibility.md` and `docs/api/breaking-change-policy.md`.

The short version:

- Public API changes are tracked in `Mediation/PublicAPI.Shipped.txt` and `Mediation/PublicAPI.Unshipped.txt`.
- CI fails for removed public APIs and unapproved additions.
- Breaking changes require explicit maintainer approval and release documentation.
